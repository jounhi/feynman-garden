# 2026-05-17 — 移动端MD阅读宽度修复、代码块复制按钮及全局响应式排版优化

## 新增

- **`src/styles/global.css`**：新增 `.code-block` 代码块容器样式（圆角卡片、边框、背景）、`.copy-btn` 复制按钮样式（hover显示、focus-within显示、移动端始终可见）
- **`src/layouts/BlogPost.astro`**：新增 client-side 代码块复制按钮脚本——遍历 `<pre>` 元素包裹为 `.code-block` 容器并注入复制按钮，使用 `navigator.clipboard.writeText()` API
- **`src/layouts/PageLayout.astro`**：同步添加代码块复制按钮脚本（与 BlogPost.astro 一致），覆盖 changelog、about、首页等所有页面

## 修改

- **`src/layouts/BlogPost.astro`**：修复 `main` 双重 `max-width` 约束导致移动端文字过窄（~267px → ~350px）；`main` 改用 `width: 100%` + `max-width: var(--content-width)`；`.prose` 移除独立宽度约束；新增移动端媒体查询适配文章内标题、代码块、列表、blockquote 字号
- **`src/styles/global.css`**：移动端媒体查询新增 h1-h4/blockquote/pre/img 字号缩放规则；`.code-block pre` 添加 `font-size: inherit` 防止全局 mobile `pre` 字号冲突；body 移动端字号从 18px 调整为 17px 并增加行高
- **`package.json`**：移除未使用的 `rehype-pretty-code` v0.14.3 依赖（与 Astro 6 内容管线 `render()` 不兼容，替换为 client-side JS 方案）
