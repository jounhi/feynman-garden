# 2026-05-03 — 博客个性化与暗黑模式

## 新增

- **暗黑模式**：全局 CSS 变量实现，跟随系统 `prefers-color-scheme`，覆盖所有页面
- **个人资料面板 (`ProfilePanel`)**：展示 QQ、邮箱等联系方式，出现在首页和关于页
- **头像组件 (`ProfileAvatar`)**：读取 `src/content/profile/` 中的头像图片
- **Profile 内容集合**：`src/content/profile/` 目录，`profile.md` 存储个人信息
- **`PageLayout.astro`**：统一页面布局，替代各页面重复的 HTML 壳

## 修改

- **`BaseHead.astro`**：添加暗黑模式闪避脚本（防白闪），更新 meta 标签
- **`Header.astro`**：适配暗黑模式，集成 ProfileAvatar
- **`global.css`**：新增 CSS 自定义属性（两套颜色方案），暗黑/亮色主题变量
- **`index.astro`**、**`about.astro`**、**`blog/index.astro`**：使用 PageLayout 包裹
- **`BlogPost.astro`**：适配暗黑模式样式
- **`content.config.ts`**：注册 profile 内容集合
- **`CLAUDE.md`**：更新项目文档

## 删除

- `.claude/skills/prototype-prompt-generator/`：移除未使用的 skill 定义
