# 2026-05-19 — 内容架构迁移：统一所有文字内容至 blog collection

## 修改

- **`src/content.config.ts`**：blog schema 新增 `categories` 可选字段；移除 `changelog` 独立 collection 定义
- **`src/content/blog/关于/关于我.md`**：从 `about.astro` 和 `profile.md` 提取个人介绍内容，新建为 blog 文章
- **`src/content/blog/changelog/`**：changelog 3 篇文章整体迁移至 blog 子目录，frontmatter 统一为 blog schema（`date`→`pubDate`，新增 `description`）
- **`src/pages/about.astro`**：移除硬编码 HTML，改为 `getCollection('blog')` 查找 `关于/关于我` + `render()` 动态渲染
- **`src/pages/changelog/index.astro`**：改为从 blog collection 中筛选 `id.startsWith('changelog/')` 的文章，`date`→`pubDate`
- **`src/pages/blog/index.astro`**：blog 列表过滤掉 `changelog/` 和 `关于/` 路径的文章，避免非文章内容混入主列表

## 删除

- **`src/content/changelog/`**：整体移除，所有 changelog 文章已迁入 `src/content/blog/changelog/`
